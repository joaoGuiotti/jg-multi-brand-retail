# Quickstart: Finance Module

## Backend
The finance module calculates Cash Flow and DRE dynamically.

1. Ensure `pdfmake` is installed: `npm install pdfmake` in `apps/backend`.
2. Generate receivables automatically upon sale completion if payment method is deferred.

## Frontend
1. Access the module via `/finance`.
2. Ensure you are logged in as `ADMIN` or `SUPER_ADMIN`.
